# creative — Lern-Repo (Selbstbau)

Du baust die Projekte **selbst**. Anleitung, Code, Vorschau — auf dem Handy.

## Auf dem Handy

Im **Safari oder Chrome** öffnen (nicht in der Cursor-App):

**[Projekte öffnen](https://rawcdn.githack.com/Bvault1420/creative/4d5a6b9f307d878043db003153497dc2da33fc3c/lernen/index.html)**

1. **Fang den Punkt** — Anfänger, Mini-Spiel, 5 Schritte, wenig Code  
2. **Stimmungslicht** — etwas mehr, 11 Schritte  

Dann: Anleitung lesen → Code abschreiben oder übernehmen → Vorschau.

Falls die Seite noch das alte Stimmungslicht ohne Startseite zeigt: hart neu laden. In der App unter Schritte **Fortschritt löschen**. Branch-Links von githack bleiben oft hängen — deshalb die feste Commit-Nummer oben.

## Am Computer

Arbeitsordner unter `projekte/`. Lösungen erst anschauen, wenn du steckenbleibst: `loesungen/`.
