# creative — Lern-Repo (Selbstbau)

Du baust die Projekte **selbst**. Anleitung, Code, Vorschau — auf dem Handy.

## Auf dem Handy

Im **Safari oder Chrome** öffnen (nicht in der Cursor-App):

**[Projekte öffnen](lernen/index.html)**

1. **Fang den Punkt** — Anfänger, Mini-Spiel, 5 Schritte  
2. **Stimmungslicht** — etwas mehr, 11 Schritte  

Dann: Anleitung lesen → Code abschreiben oder übernehmen → Vorschau.

## Am Computer

Arbeitsordner unter `projekte/`. Lösungen erst anschauen, wenn du steckenbleibst: `loesungen/`.
